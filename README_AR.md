# دليل أدوية لبنان — مشروع Android أولي

## ما الذي يحتويه المشروع؟
- واجهة عربية/إنجليزية.
- بحث بالاسم أو المادة الفعالة.
- فلتر تصنيف دوائي اعتماداً على رمز ATC الموجود في بيانات الوزارة.
- فلتر دواعي استعمال جاهز لربطه بقاعدة indications موثقة.
- تخزين محلي عبر LocalStorage لعرض آخر نسخة دون إنترنت.
- محاولة جلب ملف Excel الأحدث من صفحة أسعار الأدوية الرسمية التابعة لوزارة الصحة اللبنانية، ثم قراءته والتحقق من وجود سجلات قبل اعتمادها. مصدر ملف Excel الحالي هو قائمة الأدوية المسوّقة (WebMarketed)، لذلك لا يثبت وحده اكتمال جميع الأدوية المسجّلة غير المسوّقة.

## ملاحظة مهمة حول الاكتمال
هذا إصدار هيكلي أولي، وليس APK جاهزاً للتثبيت. بيئة الإنشاء التي أُنتج فيها المشروع لا تحتوي Android SDK أو Gradle، لذلك لم أتمكن من بناء APK فعلياً أو اختباره على هاتف. كما أن ملف الوزارة الذي تم التحقق منه هو ملف أسعار/مستحضرات، وليس نشرة دوائية كاملة؛ لا يحتوي بالضرورة على دواعي الاستعمال أو التحذيرات أو النشرات. لذلك لا يعرض التطبيق استعمالات دوائية غير موثقة ولا يدّعي أن هذه المعلومات متوفرة لكل مستحضر.

## بناء APK
1. افتح المجلد في Android Studio (إصدار حديث يدعم Android Gradle Plugin 8.7.3).
2. انتظر مزامنة Gradle وتنزيل الاعتماديات.
3. اختر Build > Build APK(s).
4. سيظهر ملف APK ضمن `app/build/outputs/apk/debug/` إذا نجح البناء.

## مصدر البيانات الرسمي
- قاعدة الأدوية الوطنية: https://www.moph.gov.lb/ar/Drugs/index/3/3974/lebanon-national-drugs-database
- صفحة قائمة الأسعار: https://www.moph.gov.lb/en/Drugs/index/3/14046/letter:N/page:3/sort:Drug.brand_name/direction:DESC

## قيود الإصدار الحالي
- تحديث Excel يحتاج اختباراً عملياً على ملف الوزارة الحالي؛ بنية الأعمدة قد تتغير.
- التحديث التلقائي يعمل عند فتح التطبيق مع توفر الإنترنت أو عند عودة الاتصال والتطبيق مفتوح. لا يوجد تحديث بالخلفية بعد إغلاق التطبيق في هذه النسخة.
- تصنيف ATC يعتمد الحرف الأول فقط، وهو تصنيف مجموعات علاجية كبرى، وليس تشخيصاً أو توصية علاجية.
- لا تستخدم التطبيق لاتخاذ قرار علاج أو جرعة أو إيقاف دواء.

دليل أدوية لبنان

تطبيق للبحث عن الأدوية المتداولة في لبنان.

الميزات

- البحث عن الأدوية بالاسم.
- تصنيف الأدوية حسب الفئة العلاجية.
- عرض معلومات الأدوية ودواعي الاستعمال عند توفر بيانات موثوقة.
- دعم العربية والإنجليزية.
- العمل دون إنترنت بعد تحميل البيانات.

حالة المشروع

نسخة أولية قيد التطوير والاختبار.

تنبيه: المعلومات المعروضة لا تغني عن استشارة الطبيب أو الصيدلي.
